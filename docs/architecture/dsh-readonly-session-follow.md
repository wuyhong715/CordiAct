## 本地模型

[状态归约器](../../deepseek-harness/src/main/kotlin/com/cordiact/harness/deepseek/ReadOnlySessionFollow.kt)只保留当前所选目标的一份内存状态：当前会话日志位置 `cursor`、是否附着 Agent、是否运行。`cursor` 不是落盘确认、恢复令牌或传输序号。没有 URL、凭据、网络、磁盘、命令、历史、工具输出或模型输入。现有写向抽象不是它的传输层，两者不衔接。

- 目标组合独立绑定连接、CordiAct 本地工作区和远端会话。目标字段是本地路由身份，非服务端授权凭据；[受信交付](../../deepseek-harness/src/main/kotlin/com/cordiact/harness/deepseek/ApprovedFollowPipe.kt)绑定已核验的独占管道、远端工作区、会话和一次性凭据；不从响应猜测归属，也不把旧响应重新盖章。[固定证书 TLS 连接器](../../deepseek-harness/src/main/kotlin/com/cordiact/harness/deepseek/PinnedFollowTlsConnector.kt)在交付前验证已审批的证书与协议。证书指纹、端点和目标须经受信渠道预先绑定；不做自动发现、系统 CA 回退或信任首次连接。[签名配对原型](../../deepseek-harness/host-follow/README.md#预置信任的配对原型)在隔离控制信道中验证独立预置的签名键、精确路由、随机挑战与专用凭据的绑定；从挑战起计 15 秒，批准、连接、握手和排队不续期。回复另用每路由独立预置的密钥做 AES-256-GCM 认证加密，并绑定同一挑战；新路由入口不接受明文回复。Host 在显示操作者审核之前，要求客户端提交覆盖同一精确路由与挑战的 HMAC 持钥证明；仅有挑战或证明不匹配时不弹审核。每份验证成功的挑战只进入一次审核。证明不认证消息当前传递者，不替代密钥预置、轮换、操作者批准或数据面的独立授权。
- [路由控制器](../../deepseek-harness/src/main/kotlin/com/cordiact/harness/deepseek/FollowRouteController.kt)按已配置路由、审批和载体分别核验原对象。重新配置或显式开启新挑战时立即清除旧状态，关闭旧握手与原投影；每次选择或重连都创建新世代，即使所有 ID 相同。晚到的响应或配置回调不能发布、读取或关闭新状态。必须先收到当前世代的完整基线。进程内归约器会忽略已处理编号；[管道适配器](../../deepseek-harness/src/main/kotlin/com/cordiact/harness/deepseek/FollowPipeReceiver.kt)则严格使用 Host 帧自带的交付序号，首个为 `0`，重复、跳跃、游标倒退、畸形内容均结束当前世代并清除内容，绝不在客户端重新编号。编号不是 Host 会话日志游标；后者允许相同或跳增。
- 断线或收到撤权时立即清除当前投影，不把旧内容当成在线状态；离开页面可清除整个选择。[端侧生命周期](../../deepseek-harness/src/main/kotlin/com/cordiact/harness/deepseek/FollowPipeLifecycle.kt)一次接管一个已核验、独占的载体；终止时先清状态，再请求取消原载体。首帧最长等 3 秒，端侧投影最多保留 30 秒，或以调用方提供的更早授权期限为准。即使正常流保持空闲或继续有更新也不续租；读入和状态读取同步复核单调截止，不依赖后台定时回调先执行。不自动重连、重放、读历史或恢复授权。本地截止不证明网络分区，也不代替 Host 撤权。[单次读循环](../../deepseek-harness/src/main/kotlin/com/cordiact/harness/deepseek/FollowPipeClient.kt)接管其绑定的流，用独立执行器读取有界字节，不打开进程或认证；读取 EOF、错误、执行器拒绝或选中变化时，清退同一载体。截止时取消须能解除实际阻塞读取，不能只标记逻辑关闭。

Android 侧已有[未注册的显式工厂](../../app/src/main/java/com/cordiact/app/deepseek/AndroidFollowRuntime.kt)：API 26–28 返回不可用，不尝试旧 TLS 或私有 ALPN；API 29 起给路由控制器传入包含休眠时间的单调 `SystemClock.elapsedRealtimeNanos`。工厂未接启动、界面、密钥或载体，不自动联网；SDK 桩编译与注入时钟的 JVM 用例不代表 Android TLS 或休眠已实机验证。同一时钟贯穿配对、TLS 握手和投影。前台恢复时，以原路由调用 `recheck`，不等待调度器重启即可清退已过期的挑战、待连接审批、握手和投影；随后重新读取状态再渲染。晚到的回复在解密之前检查原挑战身份和截止时间；即使没有收到前台回调，超时的待连接审批也不会开始握手。该检查不唤醒设备、不续租、不重新连接。可选的 [Activity 生命周期绑定](../../app/src/main/java/com/cordiact/app/deepseek/ActivityFollowBinding.kt)采取更严格的策略：暂停前取消整个当前本地尝试，恢复仅开放显式操作，不恢复旧流；页面还必须持有自己的不透明 Route 句柄，退出时按原句柄清除，旧页面回调不能清除替代 Activity 的同 ID 路由；异步配置也须在发起时获取一次性意图，同时核对原路由（首次配置必须为空）并固定新目标。暂停、清除原路由、显式丢弃、新请求或关闭后到达的旧结果不能安装或替换信任。尚无路由时，退出页面应显式丢弃仍待提交的意图。销毁时关闭控制器、释放内存信任并注销回调。绑定只接受原 Activity 的事件，不接任何生产页面、启动、密钥或载体。SDK 桩编译和 JVM 用例覆盖未恢复时拒绝、暂停解除阻塞及旧回调隔离；已加入[设备仪器测试](../../app/src/androidTest/java/com/cordiact/app/deepseek/ActivityFollowBindingInstrumentationTest.kt)，用不导出的 Debug Activity 验证真实暂停、恢复和重建，并测试实际 Android TLS 握手在暂停时关闭回环连接。常规 Android CI 增加测试 APK 编译及基于 XML/ZIP/DEX 的 release 排除 Debug 夹具检查，设备用例纳入现有 API 29/35 仪器测试。通过[本地类型校验脚本](../../verification/compile-android-follow.sh)使用 Android SDK 与真实 AndroidX 依赖完成仪器源码编译；另有[平台 TLS 仪器用例](../../app/src/androidTest/java/com/cordiact/app/deepseek/FollowLoopbackTlsInstrumentationTest.kt)：精确证书指纹与 ALPN 才能读取首帧，EOF 清除投影；错误指纹或未协商 ALPN 不释放请求凭据。同一回环夹具已在宿主 JDK 17 跑通，但本地流程不生成 APK，尚无 Android TLS 提供程序或实机运行结果。调用方也可用原路由和挑战显式取消一次本地尝试，清退未提交挑战、在途交接、待连接审批、握手或已接管的投影；不删除预置信任或影响后来的尝试，也不等同于 Host 撤权。

回环 Host 可以显式导出[公开路由描述](../../deepseek-harness/host-follow/README.md#预置信任的配对原型)。客户端严格解析后，仍须由调用方认证来源、明确选择本地目标与远端工作区，并单独交付路由密钥。描述不会触发连接、不携带凭据，也不是信任断言；范围不匹配时不替换当前路由。

## Host 插件验证

[进程内插件](../../deepseek-harness/host-follow/README.md)在独立验证 profile 使用真实 Loader 和 DSH 活态注册目录。可信控制面与读取服务分开；后者仅接受独立的一次性、单目标、短时授权。Host 不装 Gateway、Web、LLM 或通用命令，不查冷存储，也不注册监听器。撤权、过期、解绑/归档、会话换代及插件卸载可关闭现有进程内读流。测试的数据和目录均为合成，不访问生产会话。

Node 47 项核心、IPC、配对证明与签发、一次性交接、密封、终端审批、回环 Host 装配、私有身份目录和 TLS 慢读测试通过。[带外交接](../../deepseek-harness/host-follow/pairing-handoff.mjs)只收一组显式移交的独占流，读取完整 EOF 后才交给终端审核；撤权、关闭或到达绝对截止时终止交接，不重放。固定 Loader 已通过继承管道完成轮换后的挑战交接，数据面仍不接收配对请求。私有目录回归模拟读取前后的 `ctime` 和安全权限漂移，验证不误拒；权限放宽、硬链接、大小或内容变化、读取取消仍会拒绝并清理缓冲。固定 Loader 已使用 Linux 私有目录显式启动；拒绝开放权限、路径或文件链接、非普通文件及超限文件，取消读取不会交付密钥。目录由受信调用方选择，不提供密钥配送或在线轮换。真实 Loader 已验证两套独立身份的停旧启新：旧流和端口先关闭，共享读服务不中断；新实例拒绝旧凭据、密钥证明和证书信任，客户端用独立预置的新密钥、签名公钥和指纹建立新流。证明覆盖完整路由，缺失、错误密钥、错域或重复请求均拒绝，拒绝已通过持钥验证的请求也不会再次提示。Kotlin ↔ Node 实测先拒绝缺失和篡改的证明，再接受正确证明并拒绝重放。可选的 [Cordis 装配插件](../../deepseek-harness/host-follow/loopback-plugin.mjs)只在显式进程内启动后监听；验证了启动与卸载交叉时清退，以及旧服务引用拒绝使用替代依赖。[回环装配](../../deepseek-harness/host-follow/loopback-host.mjs)由实际 TLS 证书和监听端口形成签名路由，拒绝不匹配私钥，关闭时清退审核、授权和连接。终端适配器覆盖非交互拒绝、精确确认码、错误回复、超时和取消；PTY 仅证明交互逻辑，不证明生产操作者身份。固定路由覆盖单次审核对象的作用域、过期、取消与替换，以及挑战去重、失败签发不重试、替换和在途撤权；真实回环慢读端让写回调停滞，Host 在最后一次拉取后约 3 秒关闭，未再取下一帧。该测试使用高频合成源，不是生产吞吐或内存基准。另有 1 项真实 Loader 测试从空目录用锁定 npm 包和固定 Git 对象重建后通过，复现命令已纳入仓库 CI。原样 npm 固定包因 Loader 缺导出无法启动，混合验证工件不是可部署制品。[同树正式构建验证](../../deepseek-harness/host-follow/README.md#用同一源码树的正式构建验证)单独执行，不在任何模式间自动回退。Linux arm64 的干净固定 checkout 经冻结安装后，官方工件构建 8 阶段通过，并在禁网命名空间直接运行已构建 CLI，通过同一个合成 profile。无监听器模式通过继承管道覆盖首帧、更新和撤权断流；独立的 `--loopback-tls` 模式将同一 Loader 的授权服务接入 Host 配对控制器，固定 CLI 从真实 PTY 读取测试拒绝与随机确认码。已核对终端显示的路由与指纹，拒绝不触发签发；确认不经测试 IPC，终端也不显示 bearer。Node 测试客户端用独立预置的密钥打开密封回复并核验签名与完整路由，再经专用 TLS 读取合成会话。验证错域、重复挑战与凭据、非专用凭据和 HTTP 前缀拒绝，并确认读取插件卸载时，依赖它的装配服务取消注册、现有流关闭、回环端口拒绝新连接，旧启动和审批引用不能再用。TLS 载体未加入默认 profile；本地验证使用 `127.0.0.1`，单独启用 `lo` 的隔离工作流尚未远端运行。

## 接入前必须补的证据

1. 提供固定版本 Host 装配和独立认证主体（**非 owner**），服务端默认拒绝。只允许对显式授权目标读取脱敏的状态投影；不接受默认 Web/控制凭据，不做低权限失败后回退。投影须在 Host 输出有界字段，不能先把完整队列传进手机再隐藏。
2. 用无生产数据的 Host 集成/协议测试，证明合法目标能读，另一会话和另一工作区被拒绝；对 prompt、cancel、fork、activate、上传、附件、通用控制、互动回复及替代 RPC/HTTP 入口进行拒绝测试。若要求宿主不写盘，固定可审计存储配置并覆盖冷观察。
3. 继承管道与固定 Loader 的合成 TLS profile 已验证关闭及卸载清退；尚缺生产受信配对、非回环传输策略、外部载体背压、跨网静默断线及 Android 端侧清除的联合证据。回环故障注入只验证本地截止，不验证设备休眠、网络分区探测或重新连接。断线、关闭或重连时，载体、目标和凭据的世代不能替换旧回调身份。未验证前不新增 Android 连接入口。

# 批一：侧边对话抽屉

状态：实现完成，CI 验证中（2026-11-09）。基线分支 feat/ui-rebuild-quality，提交 03d64ae。

## 范围与依据

只实现侧边栏，设置页留批二。以用户提供的 DeepSeek 参考图提取结构，不复制品牌，也不添加后端没有的入口。实现基于真实契约（WorkspaceContracts.kt、ConversationContracts.kt），不复活旧 ui/。

## 视觉与布局

- 浅色，抽屉宽为屏宽 86%，上限 360dp；右侧保留可点击遮罩。
- 顶部品牌名 CordiAct、副标题、关闭按钮；其下是描边圆角「新对话」主按钮。
- 「工作区」标题行带搜索、新建工作区两个图标按钮；搜索展开为单行输入，匹配工作区名和会话标题，不搜索正文。
- 主体是唯一的 LazyColumn：工作区行（展开箭头、文件夹图标、名称、更多菜单）→ 缩进的会话行。
- 当前工作区的箭头默认展开；当前会话用浅色底 + `selected` 无障碍状态；运行中的会话显示状态点与「执行中」描述。
- 搜索时临时展开所有命中分组，不改变用户手动折叠状态；工作区命中时列出该组全部会话。
- 底部固定：分隔线、设置入口（右侧标注「批二」）、工作区隔离说明。设置随列表滚动保持固定，避开系统导航栏。
- 会话行最小 48dp、工作区行 52dp，大字体按内容增高；所有图标按钮至少 48dp 触达。图标为自绘 Path，无第三方图标库。

## 交互

1. 「新对话」在当前工作区创建；分组菜单可在指定工作区新建。成功选中后关闭抽屉。
2. 工作区名称点击：选中该工作区最近的用户会话，没有则创建；箭头只负责展开/收起。
3. 会话点击：按真实 workspaceId 选择；仅成功提交后关闭抽屉。加载中禁用重复操作，避免双建。
4. 新建工作区：弹窗输入，trim 后非空、≤80 字符、不含换行/控制字符；创建后激活并打开首条空会话。失败保留弹窗与输入，并在弹窗内显示错误。
5. 工作区更多：在此新建对话、重命名工作区。重命名失败不关闭弹窗，成功后更新侧栏与标题。
6. 会话管理（重命名/归档）本批不提供：`SessionManagerService` 没有对应接口，不做前端假管理。
7. 遮罩、关闭按钮、系统返回均可关闭抽屉；弹窗优先关闭自身。
8. 空工作区显示「还没有对话」；搜索无结果显示「没有匹配的对话或工作区」。
9. 设置按钮点击提示「设置将在批二开放」，不打开空白页。

## 实现边界

- `model/SidebarModels.kt`：纯 Kotlin 过滤/排序/名称校验，独立 JVM 测试。
- `ConversationSidebar.kt`：独立 Compose 组件，不依赖 ViewModel，可用静态状态测试。
- `ExperienceViewModel`：从真实工作区/会话服务构建侧栏索引（只取 `SessionKind.USER`），磁盘操作在 IO，选择复用会话缓存与前台会话切换。
- 未改聊天正文、轨迹、产物预览、输入框与 Insets 路径。

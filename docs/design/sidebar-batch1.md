# 批一：侧边对话抽屉

状态：设计定稿，2026-11-08；实现基线 feat/ui-rebuild-quality / 4a2bd6e。

## 范围与依据

只实现侧边栏，设置页留批二。以用户提供的 deepseek harness 参考图提取结构，不复制品牌或添加无后端功能的入口。最新体验层在 experience/，不复活旧 ui/。真实契约：WorkspaceContracts.kt、ConversationContracts.kt、ExperienceViewModel.kt；原先设置调研中的推测不作为实现依据。

## 视觉与布局

- 浅色默认，抽屉约屏宽 86%，上限 360dp；右侧始终保留可点击遮罩。窄屏不固定 330dp。
- 顶部品牌名 CordiAct、轻量说明、关闭按钮；描边圆角「新对话」按钮为第一主入口。
- 工作区标题旁放搜索与新建工作区。搜索展开为单行输入，覆盖工作区名与会话标题，不搜索正文或读取私密变量。
- 主体为唯一 LazyColumn：工作区 → 缩进会话。工作区图标、名称、当前标识、折叠箭头、独立更多按钮；会话最多两行，当前项浅灰紫底+无障碍 selected 状态，运行会话保留状态点。
- 默认展开当前工作区；搜索期间临时展开命中分组，不改变用户折叠偏好。工作区匹配时列出该组全部会话；会话匹配时只列命中会话。列表依更新时间倒序，同时间以 id 稳定排序；用户会话独立于内部子Agent会话。
- 底部固定分隔线、设置按钮、工作区隔离说明。不受长列表滚动影响，避开系统导航栏。设置点击用明确的「设置将在批二开放」反馈，不打开空白页或伪设置。
- 字号正常时会话行约48dp、工作区行56dp；大字体按内容长高；全部图标按钮最小48dp触达。沿用缓存 ImageVector，无第三方图标库。

## 交互

1. 新对话：在当前工作区创建，成功选中后关闭。分组更多可在指定工作区新建。
2. 工作区名称点击：选中该工作区的最近用户会话，无会话则创建；箭头只展开/收起，不改变活动工作区。
3. 会话点击：依真实 workspaceId 选择；仅提交成功后关闭抽屉。正在加载/变更时禁用重复操作，避免双建和过期请求覆盖。
4. 新建工作区：弹窗输入，trim 后不能为空，限定合理长度；创建并激活且打开首条空会话。
5. 工作区更多：新对话、重命名。本批不暴露工作区归档：默认工作区受保护，非默认归档会连带切换执行上下文，待具备工作区回收站后统一开放。
6. 源码复核修正：SessionManagerService 只有创建、读取、列举与消息接口，没有会话重命名/归档/恢复。本批不展示会话更多菜单，不使用前端假归档或另建影子数据库；会话管理接口另批补齐。工作区重命名和新建已有真实后端，本批接通。
7. 重命名工作区不取消任何后台会话，不混淆会话缓存。失败保留原选择、保留抽屉，提供错误文本和重试入口。
8. 遮罩、关闭按钮、系统返回均关闭抽屉；弹窗优先关闭自身。搜索无匹配与空工作区给明确空态，不展示示例对话。

## 实现边界

- SidebarModels：纯 Kotlin 过滤/排序/分组与输入校验，可在独立JVM验证项目测试。
- ConversationSidebar：独立 Compose，可使用静态状态进行组件交互测试，不依赖 Application。
- ExperienceViewModel：从真实工作区服务列出各组 USER 会话，磁盘操作在 IO；选择沿用会话缓存和真实 InteractionService，提交后回调驱动关闭。
- 不改模型选择、聊天正文、轨迹、产物预览、输入框和 Insets 路径。不新增产品级设置，不安装依赖。

## 验收与交付

- JVM：搜索/排序/工作区命中/特殊字符与中文/空白名称校验。
- Compose：树展开与折叠、当前项、跨组选择、搜索与无结果、新建/重命名工作区弹窗、设置反馈、长列表底部固定、窄屏可达。
- 本地 Kotlin main+test 类型检查；所有 APK 仅 GitHub Actions。完整结果以 CI 为准；无真机测试不得宣称真机体验验收完成。
- 提交至现有独立分支、运行 CI、导出 APK 供用户自行测试；不合 main、不发布、不安装、不控制手机。

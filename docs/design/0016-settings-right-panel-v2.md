# 设置右栏 V2：首批原生实现

保留现有横屏设置目录及分组，同一右栏承载 Agent 预设、提供商详情和模型声明；竖屏顺序进入。沿用设置主题、细线分组和原有分区组件。

- Agent：保留工作区/全局默认、现有模型角色及按模型限制的推理档。自定义系统提示词有独立存储键、组装预览，并在从对话输入区首次创建会话时保存为系统消息；旧版草稿不自动激活。消息投影把该段放在平台段之后、历史之前，并将它排除在自动、手动和溢出压缩的候选外。工具与权限草稿未接线。
- 提供商：右栏分「模型／连接配置」。既有凭据、协议与端点路径不变；获取模型不等同于能力实测。可手动加入请求模型 ID，启用需要按原有方式另存。逐模型编辑上下文窗口、最大输出、图片输入以及 OpenAI 兼容推理档与默认值；写入现有提供商配置存储，对启用模型的描述与请求生效。
- 不把原型中的全部字段标为已实现：逐模型工具调用/原生搜索覆盖、目录来源与恢复、手动模型长期保留（重新获取仍按原有服务目录刷新）、内置直连目录编辑不在本批。保留现有安全策略，不以设置开关解锁审批或附件检查。

# CordiAct UI v3「Lumen」设计规范（送审稿）

> 日期：2026-11-20 · 基线：main `71e26bc`（#90 会话工作台）· 状态：设计稿，未实现
> 可视化稿：`CordiAct-UI-v3-prototype.html`（同目录，手机浏览器直接打开，可点击交互）

## 0. 宣发意见 → 设计回应

| 宣发意见 | 回应 |
|---|---|
| 与其他 Agent 客户端高度雷同 | 放弃「左抽屉 + 气泡流 + 底部输入框」三件套。改为 **轨道（Track）+ 胶囊岛（Island）+ 透镜（Lens）**：对话不是聊天记录，而是一条可擦洗（scrub）的执行轨道 |
| 要有创新交互 | 6 个签名交互（§3），每个都有手势、状态和回退 |
| 统一风格 | 一套 token（§4）+ 三层材质（§5），所有页面只用这些 |
| 高扩展性 | 插件统一走 **Lens 三级表面契约**（Glance / Card / Sheet，§6），新能力不改壳 |
| 市场竞争力 | 卖点可截图可演示：「拖动看 Agent 每一步」「滑动批准」「胶囊岛实时状态」 |

## 1. 设计原则

1. **结果先于过程**：答案在前，过程收进轨道，按需展开。
2. **一处状态**：运行、审批、错误只在胶囊岛出现一次，不在列表、底栏、卡片重复。
3. **手指可达**：所有高频操作在屏幕下 40%；顶部只放状态。
4. **结构经典 iOS，浮层 Liquid Glass**：内容面用不透明分组列表，浮在内容上面的东西（岛、输入台、工具栏、Sheet）才用玻璃。
5. **克制的品牌**：唯一的品牌色只用于「Agent 正在做事」；静止界面基本是黑白灰。

## 2. 信息架构

```
Space（工作区）
 └─ Thread（会话）
     └─ Turn（一轮：问题 → 轨道 → 答案）
         └─ Step（模型思考 / 工具调用 / 审批 / 产物）
```

- 顶层不再是抽屉，而是 **Spaces 切换器**：在胶囊岛上左右滑切工作区，下拉岛打开全部会话（全屏 Sheet，iOS 大标题 + 搜索）。
- 原「对话 / 轨迹 / 预览」三窗 pager 取消。轨迹并入每轮的 Track；预览并入 Lens Sheet。
- 设置：独立 iOS 设置栈（大标题、inset 分组、细线包边，沿用 2026-11-16 偏好）。

## 3. 签名交互

### 3.1 胶囊岛 Island（顶部）
- 常驻顶部居中的玻璃胶囊：`Space 名 · 会话名`。
- 运行中变形为 **活动岛**：左侧品牌色呼吸点 + 当前步骤（「读取 3 个文件」）+ 计时。
- 待审批时变为 **琥珀岛**，轻触展开审批 Sheet。
- 手势：左右滑 = 切 Space；下拉 = 会话总览；长按 = 停止运行（带触感 + 确认）。
- 动画：宽度 spring（stiffness 400, damping 0.8），内容交叉淡入 180ms。

### 3.2 执行轨道 Track + 擦洗器 Scrubber
- 每个 Turn 的过程压缩成一条 **步骤珠串**：一颗珠 = 一个 Step，颜色/形状表达类型（思考○、工具◆、审批▲、产物■），失败为红。
- 手指在珠串上横向拖动 = 擦洗，上方浮出该步骤的 Glance 预览（类似 iOS 视频擦洗缩略图）。抬手停在该步 → 展开 Card。
- 运行中珠串向右生长，末端为呼吸珠。
- 替代现有「连续工具调用折叠卡」，信息密度更高，视觉上独有。

### 3.3 输入台 Dock（底部玻璃）
- 单行玻璃输入条，左侧 `+`，右侧发送/停止二合一按钮。
- **上滑输入台 → 上下文托盘**：模型、权限档位、附件、@文件、#变量以卡片横排呈现，可拖进输入框。
- 权限档位用一个小图标常驻输入条左侧（只读/工作区/完全/自动），点按循环，长按说明。
- 键盘弹出时 Dock 贴合键盘，托盘自动收起。

### 3.4 滑动批准 Slide-to-Approve
- 审批 Sheet：风险摘要 + 命令/差异预览 + 范围（本次 / 本会话 / 本工作区）。
- 低风险：按钮「允许」。高风险（删除、凭证、外发）：**滑块批准**，防误触，iOS 关机滑块语义。
- 拒绝始终是一个普通按钮，且可附一句理由回传模型。

### 3.5 答案段落锚点 Pin
- 长按答案中任一段落 → 浮出玻璃菜单：复制、追问这一段、固定到 Space。
- 固定的片段进入 Space 的「钉板」，后续会话可 @ 引用——把对话变成可积累的资产。

### 3.6 产物抽屉 Artifacts Shelf
- 本会话产出的文件/网页/截图/diff 汇集为 Dock 上方的一排缩略卡（有产物时才出现，可横滑、可上滑收起）。
- 点开即 Lens Sheet 全屏预览。

### 形状与间距
- 圆角：岛 / 按钮 = 胶囊；Sheet 顶角 28；分组容器 14；卡片 18；珠 6。连续曲率（squircle，Compose 用 `RoundedCornerShape` + 平滑系数自绘）。
- 间距基数 4：4/8/12/16/20/24/32。页面水平边距 16（分组 inset 20）。
- 触控目标 ≥ 44pt（48dp）。

### 动效
- 默认 spring：`dampingRatio 0.82, stiffness 380`；Sheet：`0.9, 300`。
- 时长参考：微反馈 120ms，状态切换 180–240ms，页面 320ms。
- 尊重「减少动态效果」：spring → 150ms 淡入。

## 5. 材质三层

| 层 | 材质 | 组件 |
|---|---|---|
| L0 内容 | 不透明 `bg.base` / `bg.surface` | 轨道、答案、分组列表 |
| L1 浮层玻璃 | blur 24、白 62%（暗 38%）、0.5px 内高光描边、轻折射边 | 胶囊岛、输入台、浮动工具栏、产物抽屉 |
| L2 Sheet 玻璃 | blur 40、白 78%、顶部抓手 | 审批、会话总览、Lens Sheet、上下文托盘 |

- 滚动视口上下边缘渐进模糊淡出（保留既有偏好）。
- Android 12+ 用 `RenderEffect` 模糊，低端/省电降级为 92% 不透明色，不出现「整片纯色板」。

## 6. Lens 扩展契约（高扩展性核心）

任何工具/插件/MCP 只需声明一个 `LensSpec`，壳自动渲染，不新增页面：

```kotlin
interface LensSpec {
    val kind: String              // "file.diff", "web.page", "shell.run", "mcp.<server>.<tool>"
    val glyph: AppGlyph           // 自绘图标，禁止三方图标库
    fun glance(step: Step): GlanceModel   // 一行：标题 + 次要信息 + 状态（擦洗预览、岛）
    fun card(step: Step): CardModel?      // 轨道内展开卡（≤ 240dp 高）
    fun sheet(step: Step): SheetModel?    // 全屏详情（diff、网页、终端、表格）
}
```

- Card / Sheet 只能用壳提供的积木：`KeyValue`、`CodeBlock`、`Diff`、`Table`、`Media`、`Terminal`、`Web`、`Actions`。风格由壳统一，插件无法破坏。
- 未声明 Lens 的工具自动回退为通用 Lens（名称 + 参数 + 结果 JSON 折叠）。
- 同一契约同时服务：轨道珠、擦洗预览、胶囊岛、产物抽屉、审批 Sheet。

## 7. 页面清单（原型对应）

1. **对话 · 运行中**：活动岛 + 答案 + 生长中的轨道 + 产物抽屉 + 输入台
2. **擦洗预览**：手指停在第 4 颗珠，浮出 Glance，下方展开 Card
3. **审批 Sheet**：高风险命令 + 范围分段 + 滑动批准
4. **上下文托盘**：上滑输入台后的模型/权限/附件/@ 卡片
5. **会话总览**：下拉岛，Space 横切 + 大标题会话列表 + 搜索
6. **设置**：iOS 大标题 + inset 分组细线包边
7. **深色模式**：对话页暗色对照

## 8. 对现有代码的影响（过审后实施）

- 替换：`ExperienceTheme.kt`（token）、`FrostedLayers.kt`（三层材质）、`TranscriptView.kt`（Track + 答案）、`ConversationSidebar.kt` → `SpacesSheet`、`WorkbenchDock.kt` → `Island` + `Dock`、`StudioLayout.kt`（取消三窗 pager）。
- 新增：`lens/`（LensSpec + 积木 + 通用回退）、`island/`、`track/`（珠串 + Scrubber 手势）。

## 10. 变更记录
- 2026-11-20 品牌色定为淡黄（Claude 风格），中性色改暖米纸感；淡黄只做填充，文字用深蜂蜜 `#8A6510`。
- 2026-11-20 横屏（宣发需求）：Activity 未锁方向；对话阅读列居中限宽 720dp，输入台限宽 760dp，空态限宽 640dp；工具详情在横屏改为右侧面板（≤420dp / 45% 宽），不再压成底部窄条；宽度 ≥840dp 沿用常驻侧栏。
- 2026-11-20 配色二次修正：大面积回到白色（背景/表面 #FFFFFF，中性灰微暖），暖米 #F7EFD9 与深蜂蜜 #8A6510 只作强调。
- 2026-11-20 浏览器标签模式（一期）：一个标签 = 一个会话或一个插件页。侧边抽屉与右上三视图菜单移除；顶部为 [标签总览] [胶囊岛] [+新对话] 与可横滑标签条，长按横拖排序；标签总览（Safari 网格）含「已打开 / 全部会话」两段，原抽屉内容并入「全部会话」。插件通过 `TabRegistry.register(TabContributor)` 新增标签，执行轨迹与产物已改为内置插件标签。标签列表持久化（SharedPreferences），删除/归档的会话与卸载的插件自动剪除，最后一个会话标签不可关闭。待做：下拖成小窗、git 树、分叉。
- 2026-11-20 横屏指挥台（第一版骨架）：手机横置且宽 ≥720dp、当前为会话标签时，对话区替换为三栏 CommandDeck——左 260dp 会话 git 树（打开的会话标签 + 两层子 Agent，按时间排为提交点，分叉曲线、运行中光晕、失败红点），中栏展开选中节点那一轮（复用 TurnView），右 280dp 待处理队列（跨会话审批按风险排序，高风险强制走滑动批准对话框；失败工具步骤可跳转/看详情）。底部命令行沿用公共输入台，点其他会话节点会切到该会话标签，指令即发往该会话。焦点状态提升到屏幕层，跨标签不丢。未做：拇指轨、对照模式、横向时间拖动。

### 标签总览 V2（已批准）

- 大标题、设置、分段、系统边缘和「新对话／完成」原样保留；已打开默认用原卡片，另可切换到列表，按原标签顺序展示，卡片偏好横竖通用且持久化。
- 只重做「全部会话」内容：按置顶、最近平铺；搜索标题和工作区名，可同时筛工作区／运行中／待确认，不切实际工作区。横向可用宽度足够时，左栏放工作区与状态，右栏搜索和滚动列表；窄屏降为单列。翻转保留筛选，不改横屏指挥台。
- 管理迁入内容区菜单：已归档、管理工作区、自动化任务；行内保留重命名、置顶、归档，归档可撤销或从归档页恢复。只展示审批状态，不新增审批入口。

### 横屏工作台 V4

- 横屏会话入口使用独立的实体布局：系统与 IME 边缘统一处理，48dp 顶栏常驻，左板只看本会话的轮次、所选轮的轨迹或本会话产物。切左板不切会话。
- 右板按需打开：跨会话审批、当前会话失败和详情共用一个位置。宽度不足时替换正文，保留左板/标签/输入并恢复阅读位置。产物当前按会话索引，尚无轮次归属。
- 正文和命令栏为同列兄弟；附件/编辑面/模型/权限/发送一排。长输入最多三行、键盘态两行。复用草稿、附件、模型与审批。会话切换先准备草稿和数据，未提交时禁发；加载完毕后绑定会话，丢弃被更新请求取代的加载结果。

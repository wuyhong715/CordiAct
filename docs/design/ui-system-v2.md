# CordiAct UI System v2

状态：实现基准；2026-11-13。保留业务、数据、导航与安全语义，重排视觉和交互。默认浅色，同时维护深色。

## 1. 原则
1. **图标帮助定位**：设置分类、对象类型和动作使用语义图标；品牌、装饰和状态不争夺注意力。
2. **内容决定层级**：聊天正文为最高信息层级。弱化重复头像、页签、运行标签、卡片边框和阴影。
3. **操作保持原位**：附件与发送固定；键盘、聚焦和展开不能改变其水平位置。弹层锚定触发器。
4. **列表优先于卡片堆**：相关入口组成连续列表，以 1dp 分隔线分组。只有独立任务、需要容错的内容才用卡片。
5. **功能不变**：返回、键盘、IME、权限、审批、后台状态、模型能力与附件约束不能因视觉重构退化。

## 2. 视觉语言
- 气质：轻量、克制、清晰的工作台；不是控制台，也不做装饰性渐变和重拟物。
- 浅色：背景 `#F7F7F9`，内容表面 `#FFFFFF`，主文字 `#1D1D22`，次文字 `#62626D`，品牌 `#5A58B8`，成功 `#47856D`。
- 深色：背景 `#141419`，表面 `#1D1D24`，文字 `#EDEDF2`，品牌 `#AAA7FF`。
- 品牌色仅用于选中、焦点和主操作。语义色只表达状态；危险操作使用 error。
- 圆角：按钮/标签 12dp，输入与弹层 20–24dp，独立内容卡 16dp。列表组 20dp。禁止同功能跨页使用不同轮廓。
- 阴影：只给浮层 2–4dp 等效高度；普通列表和设置项不投重视觉阴影。
- 间距：页面水平 16dp；列表项最小 56dp；图标按钮 44–48dp；正文 16sp/24sp；说明 12–13sp，标题 17–20sp。

## 3. 图标系统
统一 24dp 画布、约 1.6dp 线宽，圆形端点和转角。常规单色 `onSurfaceVariant`，选中 `primary`；不加装饰性彩色底。
- 导航：菜单、返回、关闭、箭头。页签缩小图标与文字；选中用短下划线。
- 分类：模型/节点、角色/人物、连接/链路、搜索、屏幕、终端、SSH、插件/节点、凭据/钥匙、安全/盾牌、附件/文件、信息、审计/文档。
- 动作：添加、发送、停止、复制、刷新、更多、搜索、收藏。
- 对象：工作区/文件夹、对话、轨迹、预览、附件/相机/照片。
- 助手仅在空状态显示品牌，不重复大头像；消息元信息与复制为低对比辅助操作。

## 4. 页面结构
### 对话
紧凑顶栏：菜单、工作区与会话标题、状态色点/文字。二级页签轻量；内容直接位于背景，不为正文套卡。用户消息使用低对比表面色；助手正文无重边框。
空状态保留三项可点击建议，图标辅助分类，品牌只出现一次。
工具、思考和错误按可展开连续块呈现；状态用图标/色点而非巨型容器。
### 工作区抽屉
品牌、关闭、新对话构成一个紧凑头部。工作区列表采用对象图标、展开箭头、更多；选中只用浅色底和文字对比。删除“批二”等开发文案，不中英混排默认新会话名。
### 轨迹
标题显示摘要与重置。没有时序数据时，直接给轻量空状态，不展示空坐标系。已有事件采用时间线，工具行使用状态图标。图表仅在确有数据时出现。
### 预览
内容为主；工具栏采用与全局一致的图标按钮，空态与错误使用统一提示容器。
### 设置
首页为连续分组列表：左图标、标题/摘要，右箭头或状态。模型、连接、安全、数据、关于按语义分组。
“需要处理”是可扫描的任务列表，不能重复同一权限卡片。详情页保持完整业务功能，输入框、状态、主/次/危险按钮明确分层。

## 5. 输入区与弹层
- 未展开：一行固定布局 `[＋] [输入……] [发送/停止]`。
- 聚焦/已展开：附件与发送仍固定同一水平位置；模型/思考控制置于独立第二行，不改变第一行锚点。
- 附件与模型面板均锚定触发器上方；不使用无关联的居中弹窗。空间不足时夹紧到屏幕安全边距。
- 面板宽度一致、宽度有上限，使用相同表面、圆角、图标和间距；模型列表支持搜索/置顶/管理；附件面板明确能力限制。
- 转场 160–200ms，避免大幅位移；运行、审批、附件错误保留明确语义标签。

## 6. 验收
- 360dp 手机、600dp 宽屏、字体放大；浅色和深色对比。
- 键盘打开/关闭、聚焦、横竖切换、弹层打开时，＋和发送水平位置不变。
- 设置全部路由可达，重复权限不重复展示，无开发标记。
- 长 Markdown、长模型名、工具运行/失败、审批、预览、空态均可读。
- 运行生产源码编译、UI 组件测试与业务测试；静态预览只验证布局，不代替真机视觉验收。

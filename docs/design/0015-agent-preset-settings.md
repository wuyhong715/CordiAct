# Agent 预设与自适应设置

- 竖屏逐级导航；可用宽度 ≥600dp 设置用目录＋详情，目录用既有强调色 Glyph。待处理堆叠复用概览的真实状态与动作。
- 搜索服务、MCP、SSH、预设编辑复用磨砂分区滑块。横屏（以及宽布局）对齐右下，窄布局居中；编辑密钥或显示键盘时让位，既有大字体回退保留。
- 服务与连接、自动化、凭据、审计和变量列表共享细线内容容器，不更改业务操作。
- 预设库保存本机内置/用户预设，工作区覆盖全局默认；复制、新建及删除不改变旧会话。新会话接入现有 Composer 的模型和推理强度，模型无效时走现有默认选择；不支持的推理档回退自动。
- 预设指令、工具清单及范围是仅可编辑的草稿；**此版本没有把它们应用到执行**，UI 明确标注。运行时权限、审批、凭据与工具授权链路未变。后续接入需要在 Session 持久化并由既有能力与权限服务强制检查，不应只用隐藏 UI 实现。
- 内容参考：Codex 配置参考（模型/推理/审批分层）与 DeepSeek Harness 配置目录（预设和工作区边界）。

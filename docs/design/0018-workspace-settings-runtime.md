# 工作区设置 V1：运行时接线

- `AGENTS.md`、`agent.toml`、`models.toml` 的项目指令与默认值在新建普通会话、启动兜底会话和定时任务会话走统一工厂；显式分派子 Agent 仍使用自己的受控配置与模型映射，不继承其自身不能更改的父级权限。旧会话不重写。
- `tools.toml` 的 `disabledTools` 和 `searchDisabled` 是额外约束，不能授权工具。无文件继承；无效文件保守禁用工具/搜索；原全局和工作区权限继续检查。设置 UI 用修订校验写回同一份文件。
- 用户与 Agent 的工作区声明均须经用户发起检查。网络探测、凭据绑定（如填写）、选定工具或模型启用独立审批；不会发送会话正文探测。连接、授权和临时凭据仅存当前进程，不从文件、Git 回滚或重启恢复。
- 已批准的模型路由只进入其工作区的模型列表，并在生成前验证真实会话归属、声明修订和模型范围；MCP 仅发布勾选工具，在列表与执行分别校验工作区、声明修订、授权和既有策略。撤销不逆转已经发生的外部动作。
- HTTP 跳转不沿用批准。改动声明文件使对应旧批准失效。外部工具/模型列表只作为数据，不作为授权。旧客户端管理入口不等同于工作区接入。
- 首版边界：交互建立的连接需人工确认（不复用执行 Agent、自批或静默切成第三方代审），进程重启需重新确认；支持远程 Streamable HTTP MCP 与可流式模型协议，不支持把图像专用提供商绑定为聊天模型。未跑真实外部服务或真机 UI 验证时不得宣称验收。

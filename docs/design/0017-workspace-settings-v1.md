# 工作区设置 V1：本次实装与边界

- 四个设置主入口共享横屏目录和竖屏逐级导航。保留旧深链、提供商/模型声明编辑器、客户端连接管理、凭据和审计。
- 新用户会话读取 `.cordiact/agent.toml`、`.cordiact/models.toml` 和工作区根 `AGENTS.md`。已有会话不重算。旧的本地 JSON 试验格式不作为生产配置，也不自动迁移或删除。模型覆盖限制在继承路由的同一提供商内。
- `.cordiact/models.toml` 的 `[providerDrafts.<id>]` 与 `.cordiact/plugins.toml` 的 `[mcpDrafts.<id>]` 可以由设置 UI 或既有工作区文件工具编辑。字段 `name`、`endpoint`、`protocol` 是非敏感离线意图，不能注册、外连、绑定凭据或授予调用权限。
- 既有文件权限不变。仅列明的四个根配置文件可通过原文件管理器直接读写；其它隐藏路径仍拒绝，链接仍拒绝。工作区工具可用性仍由实际策略决定。
- **尚未实装**：从离线声明转独立的出站/凭据审批、目标探测、工作区路由或按工具授权与撤销；`.cordiact/tools.toml` 只保留路径，运行时不消费；非交互会话创建入口尚未统一。原管理页继续明确标成客户端操作，不作为工作区审批替代。没有以降低风险控制来宣称设计完成。

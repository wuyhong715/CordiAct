# 会话与输入框回归验收（待 Android 设备运行）

| 操作 | 预期 |
| --- | --- |
| 同一草稿批量导入一张大图 A 和小图 B，前一批仍在导入时再选 C | 三个附件均就绪，不出现序号冲突；顺序为 A、B、C。 |
| 等待就绪但不发送，杀进程并重新打开该会话 | 恢复后附件仍为 A、B、C；移除 B 再加 D，重启后为 A、C、D。 |
| 会话 A 选模型 X、B 选 Y，再切回 A；检查输入框和 `ConversationModelSelectionStore.forSession(A)` | 两者均为 X，B 的记录仍为 Y。 |
| 拍照后模拟首次导入的临时存储失败，恢复存储并点重试 | 无须重拍，原图可以导入；成功后临时源文件已删除。另走一次失败后移除，临时文件也应删除。 |
| A 发送延迟完成的行为指令，马上切到 B 并输入新草稿。待 A 分发完成后杀进程并重开 | A 输入框为空，B 的新草稿仍在；A 若在完成前已有不同的新文字，应保留新文字。 |
